# Proveniência e limites de autoria

Este repositório é uma versão de portfólio do estudo acadêmico de Sistemas Distribuídos do IFES. Ele preserva o contrato e as regras observáveis do núcleo Python/gRPC encontrado na pasta de trabalho, mas reorganiza o código, remove dados pessoais de demonstração, adiciona validação, testes e integração contínua.

O projeto acadêmico original também continha uma aplicação JavaFX, bibliotecas binárias, um PostgreSQL embarcado e fontes recuperados de um ZIP de outra equipe. Esses materiais não foram incluídos aqui e não são apresentados como autoria de Eduardo Soares Thomaz. O SQL público em `docs/schema.sql` é apenas um esquema sanitizado e não é a persistência usada pelo servidor de demonstração.

Consequentemente, este repositório comprova capacidade de explicar e executar contratos Protocol Buffers, chamadas gRPC, validação de entrada e regras de orçamento. Ele não comprova autoria do sistema JavaFX legado nem de uma integração gRPC/PostgreSQL completa.
